Java Web development and AI-assisted pair programming

In Java Web Development, students build web applications and learn to review and test their code. My study of AI-assisted pair programming compares AI-assisted, traditional pair, and individual programming, looking at motivation, anxiety, collaboration, and programming performance. A teaching example on AI-assisted code review illustrates how to check suggestions against tests and course objectives.

Student mentoring

I mentor students on software projects and research, with an emphasis on framing testable questions, designing evaluations, and explaining what the evidence supports.
